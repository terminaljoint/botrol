Windows voice agent

Use the official batch launcher instead of the unsigned EXE. It installs the open-source Python agent in your user profile and starts it in a visible console.

Download BOTROL launcher (.bat) Inspect source
After downloading, open Start-BOTROL.bat yourself. A browser cannot execute downloaded files automatically. Requires Python 3.10+, Chrome or Edge, microphone and internet. First launch asks for your BOTROL admin token and stores it in Windows Credential Manager. Keep the console running, then press Win + J. No Windows security features are disabled.
